# Aerospace Engineering Learning Platform

A tidy public learning site for aerospace engineering.

The website files are already in `docs/`. GitHub will not show them at a public URL until Pages is turned on once.

## Turn the site on (one-time)

1. Open [Settings → Pages](https://github.com/DUUDaniel/Aerospace-Technology-Learning-Platform/settings/pages)
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Branch: `main`
4. Folder: `/docs`
5. Click **Save**

Wait one or two minutes, then open:
https://duudaniel.github.io/Aerospace-Technology-Learning-Platform/
